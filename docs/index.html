轻直播 · LightLive

约 100 KB 的安卓电视 / 盒子直播客户端 —— 零依赖、Android 4.4+ 都能装。

自定义 M3U 源 · EPG 节目单 · 频道分类 · 触摸 / 遥控操作 · 自研 RTSP 播放内核

⬇ 下载 APK 在 GitHub 查看

它解决什么问题

像老电视一样「按 1 就是 CCTV1」的直播 App。不做大而全的播放器，只把台放出来、把节目单写清楚，所以只有 100 KB，老盒子也跑得动。

📺 频道号直达

遥控器数字键直接跳台，1 是 CCTV1、18 是湖南卫视，跟真实电视一样。

🗂️ 分类 + EPG

读 M3U 的 group-title 分类，每个频道带「正在播 / 下一档」节目单。

📡 自定义源

填 M3U 地址或粘贴整段内容即可播，不止局限于内置的重庆联通源。

🎮 触摸 + 遥控

没遥控器也能用：单击左右换台、点中间开列表，平板大屏都能用。

🧩 自研播放内核

RTSP(TCP) → MPEG-TS → MediaCodec 硬解；MP2 纯 Java 软解，零第三方库。

🪶 极致轻量

不用 AndroidX / ExoPlayer / VLC，release 包约 100 KB，Android 4.4+ 通用。

界面截图

播放、分类频道列表、数字键换台、设置页一览。

三步用起来

  • 打开 Releases 下载 LightLive-*.apk，拷到电视 / 盒子上安装（或电脑 adb install -r LightLive-*.apk）。
  • 在桌面找 轻直播（蓝紫渐变 + 白色电视图标），打开就能看内置频道。
  • 进设置页填 M3U 地址 / 粘贴内容换源；或在同局域网用手机/电脑打开 http://盒子IP:8965 填源。

想自己编译？仓库根目录执行：

./gradlew assembleRelease
# 产物：app/build/outputs/apk/release/LightLive-3.0.0.apk

关于包名

包名是 com.miaomiao.qinglive，刻意不含 tv / iptv / launcher —— 小米、海信、创维等电视的安装管控会按关键词把 APK 判成「电视应用 / 运营商业务」直接拦截，跟功能无关。

现象真实原因怎么办
INSTALL_FAILED_USER_RESTRICTED没开「未知来源安装」去设置里开权限，跟包名无关
INSTALL_FAILED_VERIFICATION_FAILURE联网走了云端合规校验电视先断网再装
弹「该应用存在风险，已拦截」但 adb 能装安装器 UI 关键词策略这时包名 / 文件名里的用词才有意义

English

LightLive (轻直播) is a tiny (~100 KB, zero-dependency) Android TV / set-top-box live-TV client for playing IPTV / M3U playlists. Features: channel numbers like a real TV, categories from M3U group-title, EPG program guide (XMLTV), custom sources, remote + touch control, and a self-built RTSP/MPEG-TS player with hardware decode. Works on Android 4.4+.

Download the latest APK from Releases, or build with ./gradlew assembleRelease. Source & docs: github.com/mmaotv/cqcuiptv.
